gw3

A Rust wrapper for Guild Wars 2 official API v2 and Guild Wars 2 Wiki read APIs. It ships a single gw3 binary for CLI usage and MCP service mode.

GitHub Specification

Public Coverage

gw3 public routes
gw3 public get skins --ids 4674 --lang zh
gw3 public page maps --page 0 --page-size 5 --lang zh
gw3 public call recipes_search --query input=46747

High-Frequency CLI Shortcuts

cargo install gw3
gw3 api get /v2/build
gw3 item get --ids 19684 --lang zh
gw3 wiki search "Legendary armor"

Run Live Examples

cargo run --example public_api
cargo run --example wiki_search -- "Legendary armor"
cargo run --example wiki_page -- "Legendary armor"

MCP

gw3 mcp serve
