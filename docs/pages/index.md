# gw3 Documentation Pages

`gw3` is a single-binary Rust wrapper for Guild Wars 2 official API v2 and Guild Wars 2 Wiki read APIs.

Start here:

- [Quick demo](./quick-demo.md): run public API, item, trading post, Wiki, and MCP examples.
- [Official API wrapper specification](../spec/official-api-wrapper.md): current behavior contract for version `0.0.1`.

The first release is read-only. It does not read the game process, automate gameplay, persist API keys, or expose Windows internal interfaces.
